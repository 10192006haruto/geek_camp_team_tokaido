# ここメシ

**旅先で「ここで何を食べよう？」を見つける。**

現在地の周辺にある飲食店を探し、クチコミに登場する料理と、その根拠を確認できるスマートフォン中心のWebアプリです。Geek Camp 2026 Vol.6のチーム東海道で開発しています。

## できること

- 現在地から500m・1km・3kmの範囲で飲食店を検索。
- 気分や「営業中のみ」の条件で、最大5件の候補を表示。
- 店舗の写真・料理名・距離・営業時間を確認。
- 料理の根拠となったクチコミの引用を店舗詳細で確認。
- Google Mapsで店舗への経路を表示。
- 位置情報やAPIキーを使わず、架空店舗のデモを体験。

Google Placesから取得したクチコミをGeminiで解析し、料理名と引用を抽出します。引用は原文と照合してから表示します。クチコミの料理が現在も提供されていることや、ご当地料理であることを保証するものではありません。

気分による並べ替えは料理名・ジャンルのキーワード判定です。未対応の気分は距離順とし、気分に合わないことだけでは候補から除外しません。

## ローカルで試す

アプリ本体はリポジトリ直下ではなく、`geekcamp_team_tokaido/`にあります。Node.jsとnpmを用意し、リポジトリのルートから実行してください。

```sh
cd geekcamp_team_tokaido
npm ci
cp .env.example .env.local
npm run dev
```

すでに`.env.local`がある場合は、コピーせず既存の設定を利用してください。

[http://localhost:3000](http://localhost:3000)を開き、「位置情報を使わず、デモで試す」を選ぶと画面を確認できます。初期設定はモックのため、外部通信やAPIキーは不要です。通常検索のモック店舗は東京駅周辺に配置されているため、離れた現在地で検索すると0件になる場合があります。

実店舗の検索には、`.env.local`で`RESTAURANT_DATA_SOURCE=places`を指定し、Google PlacesとGeminiのAPIキーを設定します。**実APIの利用には料金が発生します。** 設定方法と注意点は[アプリのREADME](geekcamp_team_tokaido/README.md#店舗データの取得元モック実api)を参照してください。

## 技術構成

| 用途 | 技術 |
| --- | --- |
| 画面・検索API | Next.js 16 / React 19 / TypeScript |
| スタイリング | Tailwind CSS 4 |
| 周辺店舗・クチコミ・写真 | Google Places API (New) |
| クチコミからの料理抽出 | Gemini |

画面と検索APIは同じNext.jsアプリ内で動作します。外部APIへのアクセスと料理抽出はサーバー側で行います。
